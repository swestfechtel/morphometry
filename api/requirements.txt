# Pinned dependency set for the API image (swestfechtel/morphometry_api): the FastAPI service,
# the RQ worker and the morphometry library they import.
#
# WHY THIS FILE EXISTS
# --------------------
# Same discipline as morphometry/requirements.txt: every version is exactly the one the repo-root
# requirements.txt (the research venv) holds, and the file is the COMPLETE transitive closure, so
# it is installed with `pip install --no-deps` and checked with `pip check`; a missing package
# fails the build instead of resolving unpinned. Versions in this file, morphometry/requirements.txt
# and the root requirements.txt must stay equal (tests/versioning/test_api_requirements.py).
#
# WHAT IS IN IT
# -------------
# NOT the research environment: no torch / nnunetv2 / TotalSegmentator -- inference runs in the
# separate nnunet_torsion image the worker launches with `docker run`. The first block is the
# API's own third-party imports (grep of api/, minus api/tests, api/docker, the legacy
# api/examination.py); then everything morphometry/requirements.txt holds (the API imports the
# library, including pyvista/vtk at import time); then the rest of the closure.
#
# KEEPING IT IN SYNC
# ------------------
# When a version changes, change the root requirements.txt and morphometry/requirements.txt too.
