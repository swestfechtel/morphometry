# Pinned dependency set for the torsion computation image (swestfechtel/torsion).
#
# WHY THIS FILE EXISTS
# --------------------
# The image used to `pip3 install` an unpinned list straight from the Dockerfile, so every
# rebuild resolved whatever was current on PyPI -- NumPy 2 in the 2026-06 build, against the
# `numpy==1.26.4` the research venv pins in the repo-root requirements.txt. The image and the
# environment the measurements are developed and golden-tested in were therefore not the same
# code path. Every version below is exactly the version the repo-root requirements.txt holds,
# so a container built from this file runs the identical library stack as the venv.
#
# WHAT IS IN IT
# -------------
# NOT the research environment: the torsion image is pure-Python computation on masks and needs
# none of torch / nnunetv2 / TotalSegmentator / fastapi. The ten direct dependencies are the
# real import closure of `morphometry/docker/compute_torsion.py`, i.e. of
#   morphometry.{femur,hip,knee,tibia,image_io,geometry,utils,constants,bresenham}
#   + morphometry.measurements.{femur,tibia}
# and are listed first with the module that needs them. The rest of the file is their own
# transitive closure, pinned as well so that a rebuild cannot drift underneath them either.
#
# KEEPING IT IN SYNC
# ------------------
# When a version here changes, change the matching line in the repo-root requirements.txt too
# (and vice versa) -- they must stay equal, that is the whole point of the file. The
# base image is pinned to `python:3.10.16-bookworm`, the venv's exact interpreter.
